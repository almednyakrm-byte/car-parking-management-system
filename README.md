# نظام إدارة مواقف سيارات (حجز، دفع، تتبع)
==============================================

## نظرة عامة ومقصد المشروع
نظام إدارة مواقف سيارات هو مشروع يهدف إلى توفير حل متكامل لإدارة مواقف السيارات، بما في ذلك الحجز، الدفع، والتتبع. يهدف المشروع إلى توفير تجربة مستخدم سهلة وسريعة للمستخدمين، مع توفير أدوات إدارة قوية للمسؤولين.

## هيكل المشروع
هيكل المشروع يتكون من المكونات التالية:
* backend: يحتوي على كود الخادم النصي
* frontend: يحتوي على كود الواجهة الأمامية
* database: يحتوي على قاعدة البيانات
* docker: يحتوي على ملفات الدوكر

## تشغيل البيئة
لتشغيل البيئة، اتبع الخطوات التالية:
1. قم بتثبيت دوكر كومبوز على جهازك.
2. قم بنسخ المشروع إلى جهازك.
3. قم بتشغيل الأمر `docker-compose up` في مجلد المشروع.
4. قم بفتح المتصفح وادخل إلى الرابط `http://localhost:3000`.
